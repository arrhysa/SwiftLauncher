# SwiftLauncher

Лаунчер Minecraft: Electron + React + TypeScript + Tailwind.

- Все версии Minecraft (release / snapshot / beta / alpha) с установкой и прогрессом
- Профили: версия, память, папка игры, аргументы JVM
- Загрузчики модов Fabric и Forge, каталог модов Modrinth
- Вход через Microsoft (device code) и офлайн-режим
- Автоматическая Java нужной версии
- Автообновление лаунчера через GitHub Releases

## Скачать

Последняя версия: **[Releases](https://github.com/arrhysa/SwiftLauncher/releases/latest)**

- `SwiftLauncher-Setup-*.exe` — установщик. **Обновляется сам**, рекомендуется.
- `SwiftLauncher-*-portable.exe` — без установки. Сам не обновляется, но сообщит о новой версии.

Windows SmartScreen может предупредить о неизвестном издателе (приложение не подписано сертификатом): «Подробнее» → «Выполнить в любом случае».

## Разработка

```bash
npm install
npm run dev        # запуск с горячей перезагрузкой
npm run build      # локальная сборка .exe в dist-app/ (без публикации)
```

Требуется Node.js 20+.

## Как выпустить обновление

1. Внесите изменения и закоммитьте их в `main`.
2. Создайте и отправьте тег с новой версией:

   ```bash
   git tag v1.2.0
   git push origin v1.2.0
   ```

3. GitHub Actions (`.github/workflows/release.yml`) соберёт установщик и portable-версию на Windows
   и опубликует их в Releases вместе с файлом `latest.yml`.
4. Установленные лаунчеры проверяют обновления при старте и раз в 4 часа, скачивают новую версию
   в фоне и предлагают перезапуск. Если не перезапускать вручную, обновление встанет при закрытии лаунчера.

Версия приложения берётся из тега автоматически, `package.json` править не нужно.

## Вход через Microsoft

Нужен собственный Azure Client ID (Public client flow = Да) и допуск Mojang для Minecraft API.
Укажите его в «Настройки → Аккаунт». Офлайн-режим работает без этого.

## Структура

```
electron/   основной процесс: установка, запуск, Java, авторизация, моды, обновления
shared/     общие типы
src/        интерфейс (React)
assets/     иконки
scripts/    сборка основного процесса и генерация иконок
```
